## About the Project

**Adriano Zendejas** is a fan-made website template created to celebrate the content, personality, and streaming journey of Adriano Zendejas, known to his community as **Shifu**.

The website was designed as a personal project inspired by my admiration for his content and the entertainment he brings to his audience.

Rather than creating another generic streamer landing page, I wanted to build a dedicated space that reflects the identity of his channel, highlights his content, and brings together information about his streaming activities.

The website is deployed on **Vercel** and was developed with the assistance of **Claude Code**, Anthropic's AI-powered coding tool.

## Design Direction

The design is inspired by the identity of the streamer's channel and the atmosphere of his content.

The visual direction aims to create a dedicated experience rather than a generic biography page.

### Design Principles

* **Creator-focused:** The creator and his content remain the center of attention.
* **Visual identity:** The design draws inspiration from the channel's recognizable imagery.
* **Clear navigation:** Information is organized to make browsing straightforward.
* **Web accessibility:** The structure can be improved and refined as the project evolves.
* **Personal creativity:** The website is a programming project motivated by genuine enthusiasm for its subject.

## Running Locally

Clone the repository:

```bash
git clone https://github.com/luisortga/adrianozendejas.git
```

Navigate to the project directory:

```bash
cd adrianozendejas
```

Open `index.html` in a browser, or use a local development server through your preferred editor.

Because this is a static frontend project, a Node.js backend is not required to serve the basic website.
